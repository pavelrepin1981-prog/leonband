Сейчас сайт занимает около 64 МБ. Самое большое видео — около 47 МБ, это допустимо для GitHub. Не загружайте отдельные файлы больше 100 МБ: GitHub их не примет.

## 2. Создание репозитория GitHub

Репозиторий создаётся в аккаунте **pavelrepin1981-prog** с именем **`leon-site`**.

Настройки при создании:

- видимость: **Public** — это позволит бесплатно включить GitHub Pages;
- не добавлять README, `.gitignore` или лицензию: всё уже подготовлено в локальной папке;
- после создания подключить репозиторий к папке сайта и отправить в него файлы.

После создания адрес репозитория будет:

`https://github.com/pavelrepin1981-prog/leon-site`

## 3. Включение публикации через GitHub Pages

В новом репозитории откройте **Settings → Pages** и установите:

- **Source:** Deploy from a branch;
- **Branch:** `main`;
- **Folder:** `/(root)`;
- нажмите **Save**.

Через 1–3 минуты GitHub покажет адрес опубликованного сайта. Пока домена нет, это будет адрес `github.io` из раздела 1.

## 4. Как публиковать изменения

### Через GitHub Desktop или сайт GitHub

1. Внести изменения в `index.html` или заменить нужный файл в папке `app/public/assets/`.
2. Открыть репозиторий LEON в GitHub Desktop или на GitHub.
3. Добавить изменённые файлы и создать коммит с понятным описанием, например: `Обновить видео в разделе «Смотреть и слушать»`.
4. Отправить изменения в ветку `main`.
5. Подождать 1–3 минуты и обновить страницу сайта.

### Через терминал

```bash
cd ~/Documents/Codex/2026-07-22/new-chat/LEON-site
git add -A
git commit -m "Кратко описать изменения"
git push origin main
```

## 5. Видео и фотографии

- Фон главного экрана: `app/public/assets/videos/leon-promo-bg.mp4`.
- Видеоролики раздела «Смотреть и слушать» размещены на Kinescope; в `index.html` хранятся только ссылки на них.
- Для новых обложек используйте формат 16:9 и сохраняйте их в `app/public/assets/covers/`.
- Для быстрой загрузки фотографий рекомендуется сжимать новые файлы до 300–800 КБ, если качество сохраняется.

## 6. Будущий домен в REG.RU

Когда домен для LEON будет куплен в том же аккаунте REG.RU, добавьте в репозиторий в корне файл `CNAME` с одной строкой — доменным именем, например:

```text
leonband.ru
```

Затем в GitHub → **Settings → Pages** укажите этот домен в поле **Custom domain**.

В REG.RU → **Домены → нужный домен → DNS-серверы и управление зоной** добавьте записи:

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `pavelrepin1981-prog.github.io.` |

После обновления DNS вернитесь в GitHub Pages и включите **Enforce HTTPS**. Выпуск сертификата GitHub сделает автоматически. Обновление DNS обычно занимает от нескольких минут до суток.

> До покупки домена не создавайте `CNAME` и не меняйте DNS-записи существующих доменов.

## 7. Важное

- Всегда храните локальную копию папки `LEON-site`.
- Не удаляйте `index.html` и папку `app/public/assets/`: в них находится весь опубликованный сайт.
- Для проверки публикации открывайте вкладку **Actions** в GitHub: зелёная галочка означает, что проверка завершилась успешно.
- Если в будущем появятся отдельные страницы, формы, Метрика или домен, дополните эту инструкцию соответствующими данными.
